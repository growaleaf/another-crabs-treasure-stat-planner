Sources & last verified date

All pages/threads below fetched and re-read directly 2026-10-21.

  1. gameskinny.com stat-priority guide — states the qualitative role of each stat (ATK = physical strikes, VIT = HP, RES = shell damage, MSG = Umami attacks) and that RES matters less early since shells are frequently replaced. Does not state a per-point percentage or flat amount for any stat.
  2. primagames.com and pcinvasion.com — independently confirm the same four qualitative stat roles. Neither gives per-point magnitudes.
  3. astucejeuxps4.com (French-language guide) — the only source found with specific per-point numbers for all four stats: ATK +7% physical damage/point, VIT +5 HP/point, RES -1 flat shell damage/point, MSG +7% Umami damage/point. A dedicated second search for each of VIT, RES, and MSG found no independent confirming source for any of the three.
  4. steamcommunity.com — user "denisbonde5" states ATK goes up "about 5% per level," conflicting with the 7% figure above on the one stat where two independent sources each ventured a specific number.

Because the ATK rate is disputed between two sources and the VIT/RES/MSG rates are each confirmed by only one source, none of the four per-point rates are hardcoded. All four are the editable fields above, pre-filled with the astucejeuxps4.com figures as a labeled starting estimate — not asserted as fact. Only the qualitative stat roles and the arithmetic relationships (point count times rate) are shipped as settled.
